3. Template Tags

Use the schema key when determining template tags. Do not invent a new key because a Google Form question title changes.

Example relationship: 

FIELD_SCHEMA key:

name

        ↓

request.name

        ↓

<?= request.name ?>

Fields mapped into the client object use the corresponding client property. 

FIELD_SCHEMA key:

email

        ↓

client.email

        ↓

<?= client.email ?>
Important: A schema key does not automatically determine whether the value belongs to request or client. The pipeline mapping determines that.

5. Maintaining Email Templates

Adding a new field

  1. Confirm the field exists in FIELD_SCHEMA.
  2. Confirm the schema key.
  3. Confirm the field is mapped into the correct data object.
  4. Add the appropriate template tag.
  5. Verify AdminEmail.html.
  6. Verify ClientEmail.html.
  7. Test the complete submission pipeline.

Source of truth

Do not edit FIELD_SCHEMA from this page. ReferenceTemplate.html is documentation only. The production FIELD_SCHEMA remains owned by the configuration system.
