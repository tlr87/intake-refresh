When the Google Form Changes

Recommended maintenance workflow.

1. Update the Form

Make the required change to the Google Form. Record the changed question, entry ID and intended schema key.

2. Update FIELD_SCHEMA

Use the schema workflow to establish the new relationship before changing dependent code.

3. Check Email Templates

Use the Email Templates wiki to identify old tags, new tags and any AdminEmail or ClientEmail sections affected by the change.

4. Check Web Form

Use the Web Form wiki to update the FluentSnippets PHP and standalone HTML versions where required.

5. Check Spreadsheet Output

Confirm that the submitted schema key is mapped to the correct spreadsheet column.

6. Test Everything

Submit a controlled test and verify the form, spreadsheet output, AdminEmail and ClientEmail.
